## Lenovo Research Notes 

# Overview 
This research covers the features and laptop compatibility of multiple Lenovo docking stations.
The purpose of this research is to understand how Lenovo docking station models have changed over time. Furthermore, this research is to help with identifying and resolving the common docking station issues found within Lenovo docking stations. 

1. Mechanical and Side-connector Docking Stations

Description: 
Lenovo mechanical docking stations are designed for specific ThinkPad laptops. Instead of connecting throuhg a separate USB-C cable, these docks attach directly to a special connector on the laptop. This makes it easier to connect multiple accessories and monitors all at once.
However, they only work with laptops that have the matching docking station connector. 

Examples: 

ThinkPad Ultra Docking Station(40AJ): This docking station was designed to be compatible with ThinkPad laptops. It provides USB-A and C ports, Ethernet, 2 DisplayPort connections, HDMI, VGA, and an audio connection.

2. USB-C Docking Stations

Description: Lenovo USB-C docking stations allow users to connect to monitors, keyboards, mice, external devices, and wired internet through one USB-C cable. However, the laptop must support the features needed by the dock. Which not every USB-C port supports video or laptop charging. 

Examples: 

ThinkPad USB-C Dock Gen 2 (40AS): This docking station provides 2 DisplayPort connections, HDMI, USB-A and C ports, and Ethernet. It uses a 90W power adapter and can provide up to 60W of charging power to a compatible laptop. 

ThinkPad Universal USB-C Dock(40AY): This docking station was designed to work with compatible Lenovo and non-Lenovo laptops. It provides two DisplayPort connections, HDMI, USB ports, and Ethernet. It supports up to 65W of laptop charging with its included 90W power adapter or up to 100W with an optional 135W adapter. Some features, such as the dock's power button, may only work with certain laptops.

3. Thunderbolt Docking Stations

Description: Thunderbolt docking stations are designed for laptops that support Thunderbolt technology. They provide a fast connection for monitors, USB accessories, and wired internet connections. These docking stations are useful for workspaces that need to connect to several monitors or transfer large sets of data. 

Examples: 
ThinkPad Universal Thunderbolt 4 Dock: This docking station supports compatible Thunderbolt 4 and USB-C laptops. It provides connections for multiple monitors, USB accessories, and wired internet. 

ThinkPad Thunderbolt 4 Workstation Dock(40B0): This was designed for more demanding ThinkPad workspaces. It supports multiple high-resolution monitors and provides additional charging power for compatible laptops.

# Cable Differences
Not all Lenovo docking stations use the same type of cable. Some workstation docks require a special cable that connects both the laptop and its power supply.

The ThinkPad Thunderbolt 4 Workstation Dock uses a special split cable. One part connects to the laptop through Thunderbolt 4, while the other connects to Lenovo's rectangular Slim Tip power port. This allows the dock to provide the additional power required by compatible workstations.

The replacement cable is 0.7 meters long and has part number 4X91K16970.

Not every Lenovo dock requires this cable:
- USB-C docks, such as the 40AS and 40AY, use a standard USB-C connection.
- The Thunderbolt 4 Workstation Dock uses its specific split cable for compatible workstation setups.
- Mechanical docks, such as the 40AJ, connect directly to a special docking connector on the laptop.

# Troubleshooting Checks:

- Identify the docking station model and check whether it is compatible with the connected laptop.

- Check that the correct cable is being used, especially for workstation docks that require a special connection cable.

- Make sure the power adapter and connecting cables are securely attached.

- If external monitors are not working, check their selected inputs, cable connections, and supported display configurations.

- If the laptop is not charging, check the dock's power adapter and confirm that it provides enough power for the laptop.

- Check whether the laptop supports the features required by the docking station, such as USB-C video or Thunderbolt.

- If the docking station is not working correctly, check Lenovo Support for available drivers, firmware updates, and installation instructions.
