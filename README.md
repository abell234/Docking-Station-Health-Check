# Docking-Station-Health-Check
The Docking Station Health Check is an interactive troubleshooting tool that guides non-technical users through common docking-station issues using a simple question-and-answer workflow. It provides step-by-step solutions and creates a summary for users who need to contact IT support.


Purpose:
Many users often struggle with docking station problems because the issue could come from the laptop, power adapter, cables, monitor, network connection, or from the docking station itself. This tool guides users through a step by step decision workflow to identify the possible causes of why their docking stations aren't working properly and give them solutions. 

Features: 
Docking Station brand specfic troubleshooting
simple question and answer format workflow
step by step guide
decision tree troubleshooting flow
soupport summary 
feedback section to improve the tool
