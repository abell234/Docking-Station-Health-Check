# Docking-Station-Health-Check
The Docking Station Health Check is an interactive troubleshooting tool that guides non-technical users through common docking-station issues using a simple question-and-answer workflow. The tool provides step-by-step troubleshooting instructions and creates a support summary for users who need to contact IT support.


Project overview:
Many users often struggle with docking station problems because the issue could come from the laptop, power adapter, cables, monitor, network connection, or from the docking station itself. The Docking Station Health Check guides users through a step by step decision workflow to identify the possible causes of why their docking stations aren't working properly and then gives recommended solutions to solve their issue. Afterwards, the user will get a summary of the steps they completed and any unresolved issues to share with IT support for faster resolution.

How it works (Step by step):
1. The user would select a docking station brand
2. Then the user will be asked about the issue. ex. power, display, network connection, etc
3. Based on what the user's problem is, they are then guided through possible checks to find the solution to their problem.
4. If the issue is resolved, the user can stop there
5. IF the issue is not resolved, the tool creates a summary of the user's troubleshooting steps completed.
6. The user can then share that summary with IT support for faster assistance.
